# HacKU_2026_TeamJopz

This is the repository of the Team Jopz in HackU 2026 Hackathon contest!

## 项目结构

```text
.
├── .github/                 # GitHub 配置
├── docs/                    # 项目文档、架构图、Statement、Handbook
├── public/                  # 静态资源
├── src/                     # 源代码
├── README.md                # 项目说明
└── LICENSE                  # 许可证
```

## 分支结构

| 分支 | 用途 |
| --- | --- |
| `main` | 稳定可演示版本，用于最终提交和展示
| `develop` | 团队集成分支，功能合并到这里联调
| `dev-<Name>` | 个人分支
