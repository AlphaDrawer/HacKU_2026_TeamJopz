## 0. 一句话定位

GaitTrace 是一个**免安装、纯网页**的步态自测工具：腰痛 / 腰突者把手机架好、侧面走一个来回，约 30 秒得到一份大白话「步态体检卡」，并能长期追踪步态趋势，在两次复诊之间**早点发现恶化**。

**Pitch 开场（真实故事）**：「我自己有腰间盘突出，步态也有问题。如果能早点监控，也许就不会拖到现在。这个工具，就是我当初想要、却不存在的那个东西。」

| **新场景** | 腰痛 / 腰突 / 术后康复者的**家中、宿舍**——两次复诊之间无客观监测 |

**端到端完整任务**：架手机 → 侧面走一个来回 → 实时骨架 → 大白话报告 →（可选）康复建议 → 自动存历史看趋势。

## 2. 目标用户

- **主用户**：20–35 岁年轻腰突 / 慢性腰痛者（学生、久坐上班族），已确诊或反复腰痛，无力承担高频物治。
- **延展用户**：家中长辈——同一套指标可作跌倒风险筛查，大字号报告天然适老（v1 不专门适配）。
- **代表画像**：小 Z，20 岁大学生，腰突半年、偶发腿麻，想每周花 30 秒知道步态有没有变差、何时该就医。

## 3. 产品形态

- 纯 Web 网页，手机浏览器直接打开，**免下载、免注册、免账号**。
- v1 聚焦手机竖屏：iOS Safari + Android Chrome。
- 中文界面、大字 + 语音引导，零专业门槛。
- 首次加载需联网获取模型；其后通过 Service Worker 缓存，**断网也能走测**。
- 视频仅在浏览器本地实时处理、看完即焚；**无个人信息、无影像离开设备**。

## 4. MVP 范围（48 小时）

**做（P0）：**
1. **步态走测 + 实时骨架**：定距直线、侧面往返，大字 / 语音引导，摄像头实时绘制骨架。
2. **大白话步态报告**：各指标绿 / 黄 / 红 + 综合评分 + 一句总结。

4. **康复动作推荐**：按结果推荐 3 个动作（静态图文 + 要点 + 禁忌），**只推荐、不跟练**。

**不做（v2+）：** 实时跟练计数、TUG 全套、老人专属常模、云端账号 / 多端同步 / 分享医生、深度体态评估。


用户唯一要做的动作是「走」；镜头角度 / 高度不达标、关键点置信度低时主动提示重测。

## 6. 步态指标

| 指标 | 大白话 | 含义 | 定位 |
|---|---|---|---|
| **左右对称** | ⚖️ 左右均不均衡 | 左右步态时间 / 幅度差异（%） | **主指标（无量纲，最鲁棒）** |
| **步间稳定** | 🔄 稳不稳 / 晃不晃 | 步间节奏变异性 CV% | **主指标（无量纲）** |
| **步速** | 🚶 走得快不快 | 前进速度 m/s | 需校准项（依赖定距 / 尺度标定） |
| **步幅** | 👣 步子迈多大 | 单步平均长度 | 需校准项 |

- 主指标对拍摄距离 / 焦距不敏感，作为评分与预警核心。
- 步速 / 步幅用「地砖 / 步数 / 身高参照 + 自动尺度标定」补偿；标定不出只给趋势、不给假精确值，报告标注「筛查级」。
- 判定结合**文献常模 + 与个人历史基线的纵向变化**，不夸大绝对精度。

**医学依据：**
- LDH 患者步速↓、步幅↓、双支撑时间↑、变异性与不对称↑（[综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC8990405/)）。
- 慢性腰痛者步速显著低于健康人（[Meta 分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC9338341/)）。
- 单手机视频姿态评估与 VICON 多数参数信度 0.84–0.98（[研究](https://pubmed.ncbi.nlm.nih.gov/38264579/)）。

## 7. 报告、预警与医疗边界

- 顶部综合分（0–100）+ 一句大白话总结；指标卡绿 / 黄 / 红；下部康复动作；底部就医提醒。
- 报告全程常驻「**筛查，非诊断**」声明。
- 就医预警（诚实、保守），任一即触发：
  - 主指标**单次严重异常**；或任一指标连续 2 次进入红色；
  - 左右不对称较个人基线明显加重；步速连续下滑；
  - 固定红旗症状提示：出现**腿麻、无力、大小便异常**应立即就诊（独立于测量）。
- 康复动作标注适用 / 要点 / 禁忌；**急性发作期、腿麻加重时停练就医**。

- IndexedDB 存储；Service Worker 真缓存模型与静态资源。
- 静态托管 GitHub Pages：仓库即交付物、Pages 即在线 demo；注意 Pages 下模型路径与 SW 缓存路径。
